# README screenshots

`web-library-light.webp` and `web-library-dark.webp` are captures of the
Libredex browser interface using the shared curated marketing library.
They were copied from the companion application's `public/images` directory
so this repository's README renders independently of that checkout.

The root README also reuses desktop captures from `apps/docs/public/images`
and `apps/docs/public/salon`, with light/dark alternatives selected through
HTML `picture` elements.

See [the marketing dataset](../../../tests/marketing/README.md) for books,
passage sources, illustrative notes, and capture instructions. Dictionary
credits and the WordNet licence are in
[`apps/docs/public/salon`](../../../apps/docs/public/salon/).

These show application views, not evidence of native installation or testing
on a particular operating system. Do not label a capture as a Windows, Intel
Mac, or Linux acceptance result without recording that separate validation.
