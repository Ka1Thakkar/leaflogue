# Leaflogue 0.1.0 — cross-platform desktop beta

Experimental prerelease `0.1.0-beta.1`. Automated source and native packaging
checks pass. Clean-desktop installation, manual updates/uninstall, and actual
Orca, VoiceOver, and Narrator acceptance remain pending. The maintainer approved
experimental publication with those limitations disclosed on 10 November 2026.
Back up your library before testing. See [release readiness](../release-readiness.md).

Leaflogue gives your books, passages, and reading notes a home on your own
computer. Start without an account, import an e-reader's highlights, or add a
paper book and your own passages.

The `0.1.0-beta.1` experimental beta includes:

- Kobo, Kindle, KOReader, PocketBook/Vivlio, Tolino, Boox, and Leaflogue JSON
  imports, with reviewed reconciliation when imported passages change.
- Markdown notes, tags, collections, threads, reading history, and search.
- Customisable Library and Statistics dashboards, daily highlights, six
  light/dark themes, custom themes, and desktop custom widget recipes.
- SQLite backups and restores, Markdown export, and portable JSON export/import.
- Optional Convex or PostgreSQL sync, plus optional AI explanations after
  reviewing the request and accepting the provider's terms.
- A self-hosted browser client, sharing the desktop interface and reading data.

## Offline dictionary and local MCP server

The desktop includes a bundled offline English dictionary and an opt-in local MCP server so an agent can work with
the user's reading library. Source and packaged-client automation passed on Mac, Windows, and Linux x64;
the ARM64 Linux package also passed native ARM64 container checks.

The first increment is read-only: list books, retrieve book details and notes,
search passages, and explore threads. Results must include stable record IDs
and available title, author, and source-location information for citations.
Ordinary text search comes first; semantic search is deferred.

The server must use the existing library contracts, return bounded results,
and have an explicit enable/disable flow. Setup must explain that passages
returned to a cloud-based agent may leave the device even though the MCP
server runs locally. It must not expose provider keys, raw database access,
or arbitrary local files.

The [agent setup guide](../../apps/docs/src/content/docs/ai/mcp.md) documents
client configuration. Release acceptance must prove
read-only behaviour, accurate citations, access removal when disabled, and
packaged operation across the supported desktop targets with isolated fixtures.
Agent write tools are a subsequent increment, with generated notes kept
separate from source passages and visible, undoable changes.

The integrated reader and optional book-file sync are assigned to
[0.1.1](0.1.1.md), not this release.

## Downloads

The beta asset set targets AppImage and tarball builds for Linux x64 and
arm64, DMG/ZIP for Mac Apple Silicon and Intel, and installer/ZIP for Windows x64; checksums; an SBOM, production audit, and build-input record per
architecture; and the matching Convex backend bundle. This experimental beta does not include a signed stable update feed.

A draft validation candidate has no claim to be the signed stable feed.
Candidate archives and their workflow records are for the remaining checks;
use the final release's ordinary download filenames after publication.

## Before installing

Read the [install guide](https://github.com/Ka1Thakkar/leaflogue/blob/main/apps/docs/src/content/docs/start/install.md).
Check the matching SHA-256 manifest before running a direct candidate download.
The maintainer approved ad-hoc Mac signatures and unsigned Windows packages
for this beta on 10 November 2026. No verified publisher certificate or Mac
notarization is claimed. Record OS prompts during clean-machine acceptance. Final AppImage updates verify
Leaflogue's signing key and require the reader to choose installation.

## Upgrade and compatibility

- First public release: development builds may need one manual download.
- SQLite schema 17; PostgreSQL schema 13; Convex schema 17 and mutation
  contract 23. Desktop compatibility accepts Convex contracts 22–23.
- Update desktops before updating a Convex deployment to contract 23.
- Back up an existing development library first. Older builds refuse newer
  schemas. JSON import merges reading data; it does not restore an older
  database schema or saved settings.

## Known limitations and pending validation

- Clean-desktop installation, manual updates/uninstall, and actual Orca,
  VoiceOver, and Narrator checks remain pending across the target matrix.
- ARM64 container and artifact checks are automated runtime evidence, not a
  normal-user clean-desktop or actual screen-reader acceptance pass.
- Mac packages are ad-hoc signed without notarization; Windows packages are
  unsigned. OS trust prompts may block installation; clean-machine prompts
  remain unrecorded. This status is approved for the experimental beta.
- There is no Flathub, Homebrew, or Windows Store listing yet.
- Some reader formats have fixture coverage without a corresponding
  real-device sample; unusual exports may need importer fixes.
- The web client leaves native file access, backups, exports, update installation,
  and custom widget files to the desktop. It requires self-hosted sign-in and
  backend configuration; it is not a public hosted Leaflogue service.
- Provider usage costs and quotas are separate from Leaflogue. The AI is
  optional and can make mistakes.

Report reproducible issues without attaching private libraries, API keys,
or database connection strings. Report vulnerabilities through `SECURITY.md`.
